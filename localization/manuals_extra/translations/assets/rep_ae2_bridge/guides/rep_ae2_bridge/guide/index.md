# 复制-AE2 桥接器

此附属模组将 **应用能源2** 与 **Replication** 相连. Replication 网络中的物质可存入你的 ME 系统, AE2 也能请求 Replication 为你合成物品.

## 目录

* [AE2-复制桥接器](bridge.md) - 连接两个网络, 能量共享与优先级
* [物质装配机](matter_assembler.md) - 执行 Replication 任务的高速 AE2 工作单元
* [物质存储](matter_storage.md) - 元件, 总线, 监控器以及物品->物质编码
