# 涡轮机建造器

<BlockImage id="turbine_builder" scale="4" />

**涡轮机建造器**会使用其物品栏中的物品为你建造涡轮机, 类似于[反应堆建造器](../multiblock/reactor_builder.md).

## 典型流程

1. 将建造器**放置**在你希望涡轮机外壳起始的面上.
2. **打开**界面并设置**宽度, 高度和深度**(在整合包的尺寸限制内).
3. 为建造器准备**外壳**, **玻璃**, **转轴控制器**(布局所需的每个转轴列各一个), **转轴**, **叶片**, 以及你想用于线圈的**储存方块**.
4. 选择**布局**(见[转轴与叶片](turbine_rod_and_blades.md)):
   - **高效**: 单根中心转轴; 叶片逐环向上增长(可能获得 **+3%** 高度加成).
   - **高产**: 单根中心转轴; 每层都是完整叶片环(更快达到最大蒸汽量).
   - **超流**: 多转轴网格; 在**每个转轴列上放置转轴控制器**(不会受到缺少控制器的 −5% 惩罚).
   - **网站设计**: 将设计**种子 / URL** 粘贴到设计栏中; 转轴(以及网站设计模式下的线圈选择)将按该布局放置.
   - **自定义 / 无**: 仅建造框架(自定义模式还包括线圈), 不含转子内容.
5. 选择**线圈类型**(循环切换支持的金属; 网站设计模式下也可编辑)以及**线圈层数**(位于预览下方的宽按钮旁).
6. 使用**预览**(位于居中下方, 宽度相同)与**模拟**面板查看 RF/t, 蒸汽和材料. 警告显示在**居中旁边**.
7. **标记输入**(位于建造器缓存正上方):
   - 开启标记输入时点击缓存槽位, 可设置该槽位在建造步骤中接受的物品.
   - 也可以**从 JEI 拖动物品**到缓存槽位上设置虚拟标记过滤; 双击槽位可清除.
8. 准备好后按下**建造**.

建造顺序: **外壳** → **封闭平台** → **转轴控制器**(每个转轴列一个) → **转轴** → **叶片** → 顶部内部层中的**线圈方块**.

建造器**不会**放置外部的**涡轮机控制器**或端口, 建造完成后请手动添加.

## 模拟面板

显示预期的 **RF/t** 与**蒸汽**, 线圈与叶片加成(包括任一转轴列缺少控制器时的 −5%), 以及**材料清单**. 设计有效时, 网站设计种子也会计入模拟. 按钮名称可能随版本变化; 操作时请阅读界面上的提示.
